# Vendored fonts

These static TrueType files are used only by `../generate-og.ts` to render the
site's Open Graph cards (resvg lays out text from TTF/OTF, not from the `.woff`
the site ships). They are not shipped to browsers.

Both families are licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution:

- **Inter** (`Inter-ExtraBold.ttf`, `Inter-Regular.ttf`) — Copyright The Inter
  Project Authors. https://github.com/rsms/inter
- **IBM Plex Mono** (`IBMPlexMono-SemiBold.ttf`) — Copyright IBM Corp.
  https://github.com/IBM/plex
